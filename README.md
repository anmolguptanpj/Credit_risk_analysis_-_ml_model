# Credit Risk Model

## Overview

Credit Risk Model is a machine learning and data analytics project designed to predict the likelihood of loan default or credit risk based on customer financial and behavioral data. The project focuses on identifying high-risk applicants, improving lending decisions, and minimizing financial losses using predictive analytics and machine learning techniques.

This project demonstrates practical skills in:

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Machine Learning Model Building
* Classification Techniques
* Model Evaluation
* Financial Risk Analytics

---

## Objectives

The main objectives of this project are:

* Predict whether a customer is likely to default on a loan
* Identify important factors influencing credit risk
* Improve risk assessment and lending decisions
* Analyze customer financial behavior patterns
* Reduce potential financial losses using predictive modeling

## Project Workflow

### 1. Data Collection

Imported and analyzed the dataset containing customer financial and loan-related information.

### 2. Data Cleaning & Preprocessing

Performed:

* Missing value handling
* Duplicate removal
* Data type correction
* Outlier handling
* Feature scaling and encoding

### 3. Exploratory Data Analysis (EDA)

Conducted analysis to understand:

* Loan default trends
* Customer financial patterns
* Correlation between variables
* Risk distribution across applicants
* Feature importance insights

### 4. Feature Engineering

Created and transformed features to improve machine learning model performance.

### 5. Model Building

Implemented machine learning classification algorithms to predict credit risk.

Possible models used:

* Logistic Regression
* Decision Tree
* Random Forest
* XGBoost
* Support Vector Machine (SVM)

### 6. Model Evaluation

Evaluated model performance using:

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC Score
* Confusion Matrix
